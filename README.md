# Connect 4 Fullstack

Juego clásico Conecta 4 con IA y backend para persistencia.

## Tecnologías
- React + TypeScript
- Tailwind CSS
- FastAPI
- SQLite

## Funcionalidades
- PvP y PvE
- IA básica
- Animaciones UI
- Persistencia de partidas
- Leaderboard

## Ejecutar
Frontend: npm run dev  
Backend: uvicorn main:app --reload
